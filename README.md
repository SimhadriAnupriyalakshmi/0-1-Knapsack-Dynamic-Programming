# 0/1 Knapsack Using Dynamic Programming

This project implements the **0/1 Knapsack Problem using Dynamic Programming in Python**.

## Problem

A passenger has a limited luggage capacity. Each item has a weight and usefulness value. The program selects items to maximize total usefulness without exceeding the weight limit.

## Features

* Maximum achievable usefulness
* Selected luggage items
* DP table
* Time and space complexity

## Complexity

* Time Complexity: O(n × W)
* Space Complexity: O(n × W)

## Technology

* Python
* Dynamic Programming
